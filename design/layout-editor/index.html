    How layouts would work

    ModeUI profiles are account-wide and switch on /reload; nothing switches by spec today. So DPS / Tank and Healer become two built-in layouts that a profile starts from. Each module supplies its own part of a layout (Unit Frames, ModeCDM, Buffs & Debuffs), so ModeCDM's part stays in ModeCDM.

    • A new install builds its first profile from DPS / Tank.
    • The Profiles page gets New Profile from Layout (DPS / Tank or Healer). Your current profile stays as it is; you'd make a "DPS / Tank" profile and switch to it.
    • No module defaults change for existing profiles, so nothing you've placed moves on upgrade. The layout's values live in the layout.
    • Per screen height: a layout holds 1080p positions plus its own for 1440p where they differ (here the center block 25 higher, and Ultra further right). When a profile is built, the layout uses the set nearest the game's UI height (1080 or 1440). Changing UI scale later doesn't move anything.
    • Icons 6px wider than tall throughout the layout (36 × 30, 46 × 40, 30 × 24 ...).

    Steps

    1. Your saved layout and decisions

      Read the saved DPS / Tank layout and your notes from this page, plus your answers below.

    2. Docs first

      Layouts in docs/ARCHITECTURE.md; the five bars and the DPS / Tank values in each module's doc.

    3. Preset bars (ModeCDM)

      Presets.lua, settings version 9, the preset tag in validation, Reset and default places. The bars ship with plain defaults; the layout places them.

    4. Layout registry (ModeUI)

      Layouts.lua and New Profile from Layout. A built profile is checked by every module's Initialize before it's saved, as an import is.

    5. DPS / Tank parts

      Unit Frames, ModeCDM and Buffs & Debuffs each add their part, with the values you saved here.

    6. Tests

      The new tests/layouts.lua rebuilds the layout's rectangles and fails on any overlap; then every test file runs.

    7. Merge to main, then your in-game check

      Navigation: /modeui, then Profiles. Action: under New Profile from Layout pick DPS / Tank, name it, click Switch to This Profile, then /reload; then /mcdm and Edit Mode. Required state: Unit Frames, Cooldown Manager and Buffs & Debuffs on; a Rogue with a target and a focus; out of combat. Confirmation: the screen matches this page's DPS / Tank tab at your screen setting, and your old profile is unchanged when you switch back. No push without your word.
